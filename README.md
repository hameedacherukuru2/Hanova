# Hanova

**Connecting real-world challenges with suitable startups and experts.**

## About the Project

Hanova is a platform designed to connect organizations facing real-world problems with suitable startups and experts who can help evaluate and solve those problems.

## Key Features

- Problem submission
- Startup matching
- Expert evaluation
- Problem-solving collaboration
- Role-based access

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Type

Hackathon Project
